## 1. Install dependencies

Get the [postcraft](https://www.npmjs.com/package/postcraft) package and the [Inbound Node.js SDK](https://www.npmjs.com/package/inboundemail).

Make sure you have an account on [inbound](https://inbound.new?utm_source=postcraft%20docs&utm_medium=postcraft&utm_campaign=postcraft_campaign), you will need an inbound API key.

<CodeGroup>

```sh npm
npm install inboundemail postcraft
```

```sh yarn
yarn add inboundemail postcraft
```

```sh pnpm
pnpm add inboundemail postcraft
```

```sh bun
bun add inboundemail postcraft
```

</CodeGroup>

## 2. Create an postcraft using React

Start by building your postcraft template in a `.jsx` or `.tsx` file.

```tsx postcraft.tsx
import * as React from 'react';
import { Html, Button } from "postcraft";

export function Postcraft(props) {
  const { url } = props;

  return (
    <Html lang="en">
      <Button href={url}>Click me</Button>
    </Html>
  );
}

export default Postcraft;
```

## 3. Send postcraft

<Info>When integrating with other services, you need to convert your React template into HTML before sending. Inbound takes care of that for you. You can just directly pass the React template to the SDK.</Info>

Import the postcraft template you just built and use the Inbound SDK to send it.

```tsx
import { Inbound } from 'inboundemail';
import { Postcraft } from './postcraft';

const inbound = new Inbound(process.env.INBOUND_API_KEY);

await inbound.emails.send({
  from: 'you@example.com',
  to: 'user@gmail.com',
  subject: 'hello world',
  react: <Postcraft url="https://example.com" />,
});
```

## 4. Reply to an postcraft

Use the Inbound SDK to reply to an postcraft with the same template you just created.

```tsx
import { Inbound } from 'inboundemail';
import { Postcraft } from './postcraft';

const inbound = new Inbound({
    apiKey: process.env.INBOUND_API_KEY
});

// sending an postcraft via inbound
await inbound.emails.send(postcraft.id,{
  from: "Postcraft <postcraft@inbound.new>",
  react: <Postcraft url="https://example.com" />
});

// replying to an postcraft that was received via inbound
await inbound.emails.reply(postcraft.id,{
  from: "Postcraft <postcraft@inbound.new>",
  react: <Postcraft url="https://example.com" />
});


```
