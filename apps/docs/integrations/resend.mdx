##  Send postcraft with Resend
<Tip>Resend was built by the same team that created Postcraft, which makes this our recommendation to send postcraft.</Tip>

### 1. Install dependencies

Get the [postcraft](https://www.npmjs.com/package/postcraft) package and the [Resend Node.js SDK](https://www.npmjs.com/package/resend).

<CodeGroup>

```sh npm
npm install resend postcraft
```

```sh yarn
yarn add resend postcraft
```

```sh pnpm
pnpm add resend postcraft
```

</CodeGroup>

### 2. Create an postcraft using React

Start by building your postcraft template in a `.jsx` or `.tsx` file.

```tsx postcraft.tsx
import * as React from 'react';
import { Html, Button } from "postcraft";

export function Postcraft(props) {
  const { url } = props;

  return (
    <Html lang="en">
      <Button href={url}>Click me</Button>
    </Html>
  );
}

export default Postcraft;
```

### 3. Send postcraft

<Info>When integrating with other services, you need to convert your React template into HTML before sending. Resend takes care of that for you.</Info>

Import the postcraft template you just built and use the Resend SDK to send it.

```tsx
import { Resend } from 'resend';
import { Postcraft } from './postcraft';

const resend = new Resend('re_123456789');

await resend.emails.send({
  from: 'you@example.com',
  to: 'user@gmail.com',
  subject: 'hello world',
  react: <Postcraft url="https://example.com" />,
});
```

## Set up Templates with Resend

[Resend Templates](https://resend.com/docs/dashboard/templates/introduction) are a great way to collaborate on postcraft with your team, even if they're not technical. Upload a Postcraft Template to Resend and your entire team can collaborate in real-time in the visual editor.

Here's how to get started.

### 1. Add your Resend API Key

First, sign up for a [free Resend account](https://resend.com/signup).

Next, set up the Resend integration using the Postcraft CLI:

```bash
npx postcraft@latest resend setup
```

This will prompt you to enter your Resend API Key. To get one, navigate to [API Keys](https://resend.com/api-keys) in your Resend dashboard, click **Create API key**, and ensure that the API Key is scoped to **Full Access**.

Paste the API Key into the terminal and press enter.

### 2. Upload a Template to Resend

Run Postcraft and visit the **Resend** tab of the toolbar, located at the bottom of the window.

Choose **Upload** or **Bulk Upload** to import your Template to Resend.

<video src="https://cdn.resend.com/posts/postcraft-resend-integration.mp4" autoPlay loop playsInline class="extraWidth"></video>

If you want to remove the Resend integration, run `npx postcraft@latest resend reset`.
