## 1. Install dependencies

Get the [postcraft](https://www.npmjs.com/package/postcraft) package and the [Plunk Node.js SDK](https://www.npmjs.com/package/@plunk/node).

<CodeGroup>

```sh npm
npm install @plunk/node postcraft
```

```sh yarn
yarn add @plunk/node postcraft
```

```sh pnpm
pnpm add @plunk/node postcraft
```

</CodeGroup>

## 2. Create an postcraft using React

Start by building your postcraft template in a `.jsx` or `.tsx` file.

```tsx postcraft.tsx
import * as React from "react";
import { Html, Button } from "postcraft";

export function Postcraft(props) {
  const { url } = props;

  return (
    <Html lang="en">
      <Button href={url}>Click me</Button>
    </Html>
  );
}

export default Postcraft;
```

## 3. Convert to HTML and send postcraft

Import the postcraft template you just built, convert into an HTML string, and use the Plunk SDK to send it.

```tsx
import Plunk from "@plunk/node";
import { render } from "postcraft";
import { Postcraft } from "./postcraft";

const plunk = new Plunk(process.env.PLUNK_API_KEY);

const emailHtml = await render(<Postcraft url="https://example.com" />);

plunk.emails.send({
  to: "hello@useplunk.com",
  subject: "Hello world",
  body: emailHtml,
});
```
