`EmailMark` extends TipTap's `Mark` class with an additional `renderToPostcraft()` method
that controls how the mark is serialized when exporting to postcraft HTML via
[`composePostcraft`](/editor/api-reference/compose-postcraft).

Marks are used for inline formatting like bold, italic, links, and custom text annotations.

## Import

```tsx
import { EmailMark } from '@postcraft/editor/core';
```

## EmailMark.create

Create a new postcraft-compatible mark from scratch.

```tsx
const Highlight = EmailMark.create({
  name: 'highlight',

  parseHTML() {
    return [{ tag: 'mark' }];
  },

  renderHTML({ HTMLAttributes }) {
    return ['mark', HTMLAttributes, 0];
  },

  renderToPostcraft({ children, style }) {
    return (
      <mark style={{ ...style, backgroundColor: '#fef08a' }}>{children}</mark>
    );
  },
});
```

The config object accepts all standard [TipTap Mark options](https://tiptap.dev/docs/editor/api/mark)
plus the `renderToPostcraft` method.

### renderToPostcraft props

| Prop | Type | Description |
|------|------|-------------|
| `children` | `React.ReactNode` | The content wrapped by this mark |
| `style` | `React.CSSProperties` | Resolved theme styles for this mark (empty object if no theme) |
| `mark` | `Mark` | The ProseMirror mark instance |
| `node` | `Node` | The ProseMirror node that contains this mark |
| `extension` | `EmailMark` | The extension instance, useful for accessing `options` |

## EmailMark.from

Wrap an existing TipTap mark with postcraft serialization support. This is useful when you want to
reuse a community TipTap extension and add postcraft export support without rewriting it.

```tsx
import { EmailMark } from '@postcraft/editor/core';
import Strike from '@tiptap/extension-strike';

const EmailStrike = EmailMark.from(Strike, ({ children, style }) => {
  return <s style={style}>{children}</s>;
});
```

The second argument is the `renderToPostcraft` renderer component. It receives the same props
as described above.

## .configure

Configure options on an `EmailMark` (same as TipTap's `.configure()`):

```tsx
import { Bold } from '@postcraft/editor/extensions';

const CustomBold = Bold.configure({ HTMLAttributes: { class: 'custom-bold' } });
```

## .extend

Extend an `EmailMark` with additional behavior:

```tsx
import { Link } from '@postcraft/editor/extensions';

const CustomLink = Link.extend({
  addKeyboardShortcuts() {
    return {
      'Mod-k': () => this.editor.commands.toggleLink({ href: '' }),
    };
  },
});
```

You can also override `renderToPostcraft` when extending:

```tsx
const CustomLink = Link.extend({
  renderToPostcraft({ children, style, mark }) {
    return (
      <a
        href={mark.attrs.href}
        style={{ ...style, color: '#0066cc', textDecoration: 'underline' }}
      >
        {children}
      </a>
    );
  },
});
```
