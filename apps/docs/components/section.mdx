## Install

Install component from your command line.

<CodeGroup>

```sh npm
npm install postcraft -E
```

```sh yarn
yarn add postcraft -E
```

```sh pnpm
pnpm add postcraft -E
```

</CodeGroup>

## Getting started

Add the component to your postcraft template. Include styles where needed.

```jsx
import { Section, Column, Row, Text } from "postcraft";

const Postcraft = () => {
  return (
    {/* A simple `section` */}
    <Section>
      <Text>Hello World</Text>
    </Section>

    {/* Formatted with `rows` and `columns` */}
     <Section>
      <Row>
        <Column>Column 1, Row 1</Column>
        <Column>Column 2, Row 1</Column>
      </Row>
      <Row>
        <Column>Column 1, Row 2</Column>
        <Column>Column 2, Row 2</Column>
      </Row>
    </Section>
  );
};
```
