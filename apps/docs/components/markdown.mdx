## Install

Install component from your command line.

<CodeGroup>

```sh npm
npm install postcraft -E
```

```sh yarn
yarn add postcraft -E
```

```sh pnpm
pnpm add postcraft -E
```

</CodeGroup>

## Getting started

Add the component to your postcraft template. Include styles where needed.

```jsx
import { Markdown, Html } from "postcraft";

const Postcraft = () => {
  return (
    <Html lang="en" dir="ltr">
      <Markdown
        markdownCustomStyles={{
          h1: { color: "red" },
          h2: { color: "blue" },
          codeInline: { background: "grey" },
        }}
        markdownContainerStyles={{
          padding: "12px",
          border: "solid 1px black",
        }}
      >{`# Hello, World!`}</Markdown>

      {/* OR */}

      <Markdown children={`# This is a ~~strikethrough~~`} />
    </Html>
  );
};
```

## Props

<ResponseField name="children" type="string">
  Contains the markdown content that will be rendered in the postcraft template
</ResponseField>
<ResponseField name="markdownContainerStyles" type="object" default="{}">
  Provide custom styles for the containing div that wraps the markdown content
</ResponseField>
<ResponseField name="markdownCustomStyles" type="object" default="{}">
  Provide custom styles for the corresponding html element (p, h1, h2, etc.)
  <Info>
    Note: Passing a custom style for an element overrides the default styles.
  </Info>
</ResponseField>
