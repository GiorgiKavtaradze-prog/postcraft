## Install

Install component from your command line.

<CodeGroup>

```sh npm
npm install postcraft -E
```

```sh yarn
yarn add postcraft -E
```

```sh pnpm
pnpm add postcraft -E
```

</CodeGroup>

## Getting started

Add the component to your postcraft template. Include children tags where needed.

```jsx
import { Head } from "postcraft";

const Postcraft = () => {
  return (
    <Head>
      <title>My postcraft title</title>
    </Head>
  );
};
```
