## 1. Create workspace

Create a new folder called `transactional` inside of where you keep workspace packages (generally `./packages/*`).

Include a new `package.json` and do not forget to add this to the `workspaces` of your monorepo's `package.json`.

## 2. Install dependencies

Install Postcraft to the `transactional` workspace.

```sh packages/transactional
bun add @postcraft/ui -D -E
bun add postcraft react react-dom -E
```

## 3. Add scripts

Include the following script in your `package.json` file.

```json packages/transactional/package.json
{
  // ...
  "scripts": {
    "dev": "postcraft dev"
  }
  // ...
}
```

## 4. Write your postcraft

Create a new folder called `postcraft`, create a file inside called `postcraft.tsx` and add the following example code:

```jsx packages/transactional/emails/postcraft.tsx
import { Button, Html, Head, Body } from "postcraft";
import * as React from "react";

export default function Postcraft() {
  return (
    <Html>
      <Head />
      <Body>
        <Button
          href="https://example.com"
          style={{ background: "#000", color: "#fff", padding: "12px 20px" }}
        >
          Click me
        </Button>
      </Body>
    </Html>
  );
}
```

## 5. Run preview server

Start the postcraft previews development server:

```sh packages/transactional
bun dev
```

## 6. See changes live

Visit [localhost:3000](http://localhost:3000) and edit the `postcraft/postcraft.tsx` file to see the changes.
